## 🌟 About This Repository

This is a **comprehensive, self-contained AI & Machine Learning learning repository** that chronicles a complete journey from the very basics of Python programming all the way through to cutting-edge Agentic AI systems. Every module contains hands-on notebooks, exercises, and real-world datasets.

Whether you're a beginner writing your first Python script or a practitioner diving into Transformers and RAG pipelines — this repo has you covered.

## 🚀 Getting Started

### Prerequisites

```bash
# Python 3.10 or higher required
python --version
```

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Prithvikatkar17/AIML.git
cd AIML

# 2. Create a virtual environment
python -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate

# 3. Install core dependencies
pip install numpy pandas matplotlib scikit-learn jupyter

# 4. Install deep learning dependencies
pip install torch torchvision

# 5. Launch Jupyter Notebook
jupyter notebook
```

### Quick Start by Module

```bash
# Start with Python fundamentals
cd 01_PYTHON_FUNDAMENTAL
python 01_first_program.py

# Jump to ML
cd 11_ML
jupyter notebook 01_linear_regression.ipynb

# Explore Deep Learning
cd 12_Deep_learning
jupyter notebook 02_ANN_regretion.ipynb
```
